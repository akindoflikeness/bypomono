# v1.2.0 punch list

This is the working list. `docs/CLI_GUIDE.md` is background and rationale, not
the release tracker. Open questions in that document stay out of this list
until they are decided.

## Already in the current work

- [x] Operator ratios and levels belong to operators and survive algorithm changes.
- [x] Ratio modes load five explicit starting ratios.
- [x] Put operator ratio and level controls in the contextual display.
- [x] Keep the right rail to operator power and live level meters.
- [x] Double-click ratio to the current mode's value; double-click level to unity.
- [x] Remove the keyboard display.
- [x] Give the envelope its own full-size display page.
- [x] Reversible preset deletion, overwrite, move and rename with one-step undo.
- [x] Console help, verb completion, two-line errors and live `-v` views.
- [x] Sixteen saved LFOs and thirty-two saved modulation routes.
- [x] Console input and preset-browser focus walks do not steal each other's Tab key.

## Console and preset language

- [x] Keep every submitted non-empty line in history, including failures.
- [x] Remove timestamps and the footer line-count chip.
- [x] Print the version once in the console at startup; remove it from the info pane.
- [x] Rename shipped presets with underscores; map spaces to underscores in search/save.
- [x] Replace the preset ` - ` separator with path arguments.
- [x] Rename preset verbs to `ls cd mkdir rm rmdir mv ow load save`.
- [x] Make an existing save name an error pointing to `ow`; never append `~1`.
- [x] Add argument completion for enums, preset paths and folders.
- [ ] Make bare on/off verbs queries and use real units throughout.
- [ ] Add direct verbs for every existing sound, envelope, room, Chandas and melody control.
- [ ] Add `status`, `get` and generic `set` from the parameter specification.
- [ ] Add `next`, `prev`, `init`, `where`, `clear`/`cls` and standalone-only `quit`.
- [ ] Fold `lfo`, `mods`, `bind` and `unbind` into `mod lfo`, `ls mod` and `mod cc`.
- [ ] Add clock, tempo, transport, panic, MIDI-port and bend commands.

## Sound engine

- [ ] Use one click-free gate ramp for every audio on/off control.
- [ ] Add per-operator coarse, fine, fixed Hz, detune, envelope amount, time and velocity.
- [ ] Add polyphony and unison controls to the interface and console.
- [ ] Audit envelope gain staging against the agreed ADSR contract.
- [ ] Sum carriers without dividing by carrier count; measure RMS and enforce -1 dBTP.
- [ ] Add host transport, MIDI clock timestamps and clock-source selection.

## Interface and displays

- [x] Disconnect the splash call site but retain its implementation.
- [x] Remove the header wordmark.
- [ ] Turn the header into the one-page display tab grid.
- [ ] Move the preset bar and info control together into the body.
- [ ] Make info a cog and compact its internal buttons.
- [ ] Make the display follow the control being touched; retain manual tabs.
- [ ] Add a modulation routing display page.
- [ ] Bring the bench serif and readable table spacing into the app.
- [ ] Add the persistent DSP-load indicator.
- [ ] Remove the melody rails when their replacement is settled.

## Preset and release polish

- [x] Expire the preset-delete armed state after 0.8 seconds.
- [ ] Fix preset-pane clipping and finish its keyboard walk.
- [ ] Smooth output level when a preset loads.
- [ ] Subset embedded fonts.
- [ ] Add libpng and zlib to the third-party notices.
